## ATE Figure Sufficiency Note

The generated set is strong for an ATE manuscript when paired dense reconstruction arrays are available. If Figures 1-4 are skipped, the paper should either export those arrays from the simulator/model pipeline or move dense field claims to supplementary text until array provenance is complete. Additional seasonal, stress-test, and parameter-sensitivity figures are useful as supplementary evidence rather than extra main figures unless the journal page budget allows them.

## Evidence Boundary

Measured-node panels use public operating data. Distributed temperature, pressure/head, flow, and heat-loss fields are simulator-assisted hidden states unless an input artifact explicitly provides real dense field measurements.

## Public-repository note

The ten filesets in this directory are the frozen main-paper figures. Figures 1--8 and 10 are backed by numerical artifacts retained in this repository. Figure 9 is retained as a frozen publication artifact; row-level Flensburg input and the corresponding row-level transfer files are intentionally not redistributed.
