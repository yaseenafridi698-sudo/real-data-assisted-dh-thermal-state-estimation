# Paper scope

**Manuscript:** *Real-Data-Assisted Thermal State Estimation in District Heating Networks: An Evidence-Separated Benchmark with Simulator-Assisted Hydraulics*

This repository is scoped only to that manuscript. It is not the repository for the recoverability/effective-heat-loss-conductance identification study or the transient-constrained NMPC study.

## Evidence classes

1. **Measured-node evidence:** public district-heating observations at available plant/substation nodes.
2. **Calibrated-simulator evidence:** states produced by the calibrated thermo-hydraulic reference model.
3. **Simulator-assisted hidden-state evidence:** distributed head/pressure, flow and related dense states for which the public datasets do not provide dense measurements.
4. **Controlled perturbations:** robustness/anomaly cases generated by perturbing measured operating profiles; they are not observed field faults.

The manuscript and repository must not collapse these evidence classes into a single claim of field validation.
